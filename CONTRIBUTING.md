# Contributing to fit_abundance

Thank you for your interest in contributing to `fit_abundance`.

## Reporting issues

If you find a bug or unexpected behavior, please open an issue on GitHub.

When reporting an issue, please provide:

- a clear description of the problem;
- the Python version;
- the operating system;
- the steps required to reproduce the problem;
- a minimal example or relevant input data, when possible.

## Feature requests

Suggestions for new features or improvements are welcome.

Please open a GitHub issue describing:

- the proposed feature;
- its scientific or technical motivation;
- an example of how it could be used.

## Pull requests

Before submitting a pull request:

1. Make sure the code follows the existing project structure.
2. Add or update tests when appropriate.
3. Run the test suite:

pytest
